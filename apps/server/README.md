# apps/server — Realtime Backend

The authoritative game server for BOMB RUSH 3D: game engine, multiplayer sessions, room lifecycle (create → lobby → countdown → live → result), and realtime communication.

Planned stack: Node.js, TypeScript, Fastify, Socket.IO.

This directory is reserved for the backend implementation. The working backend currently lives in a separate local workspace owned by the backend/integration developer and will be published here when the team decides to merge it.
